# Project Images & Media Assets

Place your application screenshots and screen recordings in this directory. They are referenced directly by the main `README.md`.

### Recommended Assets:

1. **`hero-overview.png`** (or `hero-dashboard.png`): High-resolution overview of the OmniCareer dashboard.
2. **`softphone-active-call.png`**: The WebRTC Softphone modal with an active call, LCD timer, and real-time SIP traces.
3. **`gemini-live-screening.png`**: The 2-Way Full-Duplex Voice Screening modal showing the live 16kHz PCM stream, decibel VU meters, and live SQL entity extraction.
4. **`sip-qa-guide.png`**: The built-in "SIP Q&A (Demo Guide)" tab showcasing the interview scripts and architecture explanations.
5. **`sql-explorer.png`**: The interactive SQLite Database Explorer showing the `candidates`, `calls`, and `recruiter_summaries` tables.
6. **`demo-recording.gif`** (or `demo-recording.mp4`): 15-45 second animated walkthrough showing a live call test and real-time transcription.
